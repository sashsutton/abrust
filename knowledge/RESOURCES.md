# Resources

## Rust
- *The Rust Programming Language* ("the book"): https://doc.rust-lang.org/book/ (`rustup doc --book` works offline)
- *Rust by Example*: https://doc.rust-lang.org/rust-by-example/
- Rustlings (small exercises): https://github.com/rust-lang/rustlings
- Crate docs: https://docs.rs

## Audio programming
- Ross Bencina, *Real-time audio programming 101: time waits for nothing*: the classic on audio-thread rules
- *The Audio Programmer* community and talks
- Robert Bristow-Johnson's *Audio EQ Cookbook*: biquad filter formulas (Phase 8)
- Will Pirkle, *Designing Audio Effect Plugins in C++*: DSP concepts transfer directly

## Open-source DAWs and Rust audio projects to study
- Meadowlark: Rust DAW project; its engine (`firewheel`) is worth reading
- `nih-plug`: Rust plugin framework with good DSP examples
- `cpal` examples folder: start here for Phase 1
- Ardour, LMMS, Zrythm: mature open-source DAWs (C++/C) for architecture ideas
